如何切换网站的深浅色模式？

本站采用 prefers-color-scheme 自动跟随系统设置。无需手动切换，改系统主题即可。

如果想强制使用某一模式，请在浏览器或操作系统层面设置，站点本身不提供独立开关。

各平台切换方法

  • Windows 10/11：设置 → 个性化 → 颜色 → 选择深色/浅色模式
  • macOS：系统设置 → 外观 → 浅色/深色/自动
  • iOS / iPadOS：设置 → 显示与亮度 → 浅色/深色/自动
  • Android：设置 → 显示 → 深色模式 / 深色主题
  • Edge / Chrome：设置 → 外观 → 主题 → 浅色/深色/跟随系统
  • Firefox：设置 → 语言和外观 → 网站外观 → 浅色/深色/系统主题

切换后无需刷新，站点会自动应用新配色。若未生效，请清除缓存（清除缓存与 Cookie）后重试。
