Edge 浏览器无限跳转或白屏解决指南

打开 hg 站点时，页面可能不停地在两个地址之间来回跳动，或者干脆一片空白。这通常是登录状态、缓存或浏览器策略互相冲突造成的，按下面的顺序处理即可解决。

先用无痕窗口（InPrivate）访问一次：如果无痕窗口正常，说明问题出在缓存或扩展，而不是站点本身。

第一步：快速恢复访问

1

打开 InPrivate 窗口：按 Ctrl+Shift+N，在其中访问 hg 站点。无痕窗口不加载扩展，也不使用原有缓存。

2

停止跳转：如果页面正在反复跳转，立即点击地址栏左侧的停止按钮，或按 Esc，防止浏览器持续占用资源。

3

回到干净状态：在无痕窗口中正常登录使用，说明账号没有问题，接下来只需清理本地数据。

第二步：清除本站点的缓存与 Cookie

1

点击地址栏左侧的锁形图标，选择「此网站的权限」或「Cookie 和网站数据」。

2

删除本站点的 Cookie 与缓存数据，然后关闭并重新打开该标签页。

3

更彻底的清理方法见 如何正确清除网页缓存与 Cookie？，请按需选择清理范围。

第三步：检查浏览器设置与扩展

1

关闭代理类扩展：广告拦截、隐私保护、脚本管理类扩展最常引发跳转循环，请逐一停用后重试。

2

检查系统代理：Edge 会跟随系统代理设置，若代理节点异常，页面可能加载到一半中断，表现为白屏。

3

关闭「启动增强」等后台功能：这类功能会缓存页面状态，偶尔导致旧跳转逻辑被复用。设置后重启浏览器再试。

4

更新浏览器：旧版本可能存在兼容问题，请确认 Edge 为最新版本。

常见原因

Cookie 被清空但本地状态仍在
页面反复回到登录页又立刻跳转回首页，形成死循环。彻底清除本站点的所有站点数据即可。
扩展修改了页面跳转
某些扩展会强制跳转或注入脚本。无痕窗口正常、普通窗口异常，基本可以确定是这个原因。
反向代理连接不稳定
页面未加载完整导致空白。参考 网络连接失败或代理超时怎么办？。
系统时间不正确
安全连接校验失败后也可能白屏。请把系统时间设为自动同步后重新加载。

仍然无法解决

  • 换一个浏览器（如 Chrome 或 Firefox）访问，确认问题是否只在 Edge 出现。
  • 若换浏览器后正常，请把 Edge 版本号与已尝试过的步骤一起反馈，便于定位兼容性问题。
  • 若所有浏览器都白屏，更可能是服务端问题，请参考 400 Bad Request 排查 与 服务器内部错误 (500)。

反馈方式见 邮件联系站长。请附上出现时间、完整网址与错误现象，截图会更有帮助。
