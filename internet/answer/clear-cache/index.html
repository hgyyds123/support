如何正确清除网页缓存与 Cookie？

登录状态异常、页面显示旧内容、反复跳转时，清除本站点的缓存与 Cookie 通常能直接解决。关键在于"只清理本站点的数据"，而不是清空整个浏览器。

建议优先只清理 hg 站点的数据。清空全部浏览数据会退出所有网站的登录，并可能影响密码保存。

推荐做法：只清理本站点

1

在 hg 站点页面中，点击地址栏左侧的锁形或调节图标。

2

选择「Cookie 和网站数据」或「网站信息」，再点击「删除 / 清除数据」。

3

关闭该标签页，重新打开后访问 hg 站点，需要重新登录一次。

4

若问题依旧，按 Ctrl+F5 强制刷新一次，绕过缓存重新加载页面资源。

缓存与 Cookie 分别影响什么

类型保存内容清除后的影响
Cookie登录凭证、偏好设置需要重新登录，设置恢复默认
缓存图片、样式与脚本文件首次打开会稍慢，显示最新版本

常见浏览器的入口位置

  • Edge / Chrome：地址栏左侧图标 → 「Cookie 和网站数据」→ 删除；或设置 → 隐私搜索和服务 → 清除浏览数据。
  • Firefox：地址栏左侧图标 → 「清除 Cookie 和网站数据」；或设置 → 隐私与安全 → Cookie 和网站数据 → 管理数据。
  • Safari：Safari 菜单 → 设置 → 隐私 → 管理网站数据 → 搜索 hg 域名后删除。
  • 手机浏览器：菜单 → 设置 → 隐私 / 清除数据，选择仅针对当前站点。

清除 Cookie 后需要重新登录。若账号开启了两步验证，请确认手机在身边，并能正常获取动态码。

什么时候需要全部清除

只有在"只清理本站点"无效，且您愿意重新登录各个网站时，才考虑清空全部浏览数据。更稳妥的替代方案是：

  • 用无痕窗口访问，验证问题是否与本地数据相关，见 推荐使用无痕模式进行测试。
  • 换一个浏览器对比，判断是否为本浏览器的数据或扩展问题。
  • 关闭扩展后再试，避免误删全部数据。

清理后仍有问题，可参考 Edge 浏览器无限跳转或白屏解决指南 与 400 Bad Request 排查。
